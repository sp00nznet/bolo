# Bolo Adventures III — original shareware release

These are the unmodified files of the **Bolo Adventures III v1.0** shareware
release, © 1993 William Soleau / Soleau Software. They are byte-identical to
the files in the original distribution archive.

They are **not** covered by this repository's MIT license. They are here under
the game's own shareware terms (from `BOLO3.DOC`):

> This game is distributed as Shareware and may be passed along to your friends
> or local BBS. A registration fee of $12.00 is requested if you find this game
> is a worthy addition to your game collection.

The package is kept complete — including `BOLO3.DOC`, `BOLO_REG.DOC` and
`FILE_ID.DIZ` — as shareware is meant to travel.

The recompilation reads these files at run time (the game also writes its
solved-puzzle record, `BOLO3.SCR`, here; that file is not tracked).
